# 토크 예산 (Torque Budget)

PER-002: 최악 조건(팔 수평 완전 신장 + 정격 페이로드 1kg)에서 J2/J3 정적 토크 ≤ 기어박스 정격.
분담 정역학 해석과 토크 계산 전체를 본 문서에 기록·검증한다 (MUST).

## 분담 구조 (MEC-001a/001b)

J2 모터+기어박스는 J2 축 동축 직결(스테이터 상완 측, MEC-001b). J3 모터는 상완 후방 연장 탑재 + 크랭크 + 평행사변형 구동 링크. 중력 모멘트 분담:
- 상완 구간 → J2 액추에이터
- 하완 구간 → J3 액추에이터

### J2 토폴로지 결정 기록 (DOC-001, v0.7 / 2026-06-13)

후보 3안 비교 후 **J2 동축 직결 + J3만 후방 배치** 채택:
- J2/J3 모두 후방 배치(구 v2 가정, T_rear=1.33)는 J2도 크랭크+커넥팅 링크 구동이 필요 — 링크 2조로 구조 복잡, J2 가동 범위가 크랭크 기구학에 제한, MEC-001 표("J3만 링크 구동")와 충돌
- 양측 동축 배치(클래식 팔레타이저)는 T_rear≈0이라 MEC-001c(후방 균형 배치 SHOULD) 예외 필요
- 채택안은 T_rear 0.61 N·m로도 토크 여유 충분(아래 표), 구조 단순, MEC-001 표와 일치
- 드라이브 측 피벗은 기어박스 출력축(⌀8)이 겸함 — CON-001 숄더 볼트 규칙은 수동 피벗 핀 대상이므로 비저촉(CON-003과 동일 논리). 반대측은 8mm 숄더 볼트 + 608ZZ(MEC-004)

## 정적 토크 식

```
T_J2 ≈ g·[(m_p + m_fore)·L1 + m_up·L1/2] − T_rear ≤ T_rated,J2
T_J3 ≈ g·[m_p·L2 + m_fore·L2/2]                  ≤ T_rated,J3
```

- T_rear = 후방 배치 J3 모터+기어박스 질량(≈0.78kg)에 의한 상쇄 모멘트 (MEC-001c). J2 액추에이터는 J2 축 동축이라 모멘트 암 ≈ 0 — 미기여 (MEC-001b)
- m_p = 페이로드 1.0kg (그리퍼 포함, PER-001)

## 기준값 계산 v4 (L1=0.225m, L2=0.275m — 모델 실측 질량 반영, 2026-06-13)

확정값: 모터·기어박스 질량(카탈로그/데이터시트), 효율 90%, 후방 모멘트 암 = rear_extension 80mm,
구조 질량 = OpenSCAD 모델 실측([mass-budget.md](mass-budget.md), `tools/mass_report.ps1`).

T_rear = (SF2423 0.38 + MG17-G20 0.40) kg × 9.81 × 0.08 = **0.61 N·m**
(v2의 1.33 N·m는 J2/J3 4유닛 전부 후방 가정 — J2 동축 직결 확정(MEC-001b)으로 J3 어셈블리 분만 인정)

실측: m_fore = 1.09kg (J4 액추에이터 650g 포함, 링크 꺾임 반영), m_up = 0.42kg. 예산 상한(1.2kg, MEC-007 v0.8) 병행 평가. 링크 꺾임(수직)은 CG 수평 위치 불변 — 본 식에 영향 없음 ([design-notes.md](design-notes.md) §3b):

| 관절 | m_fore=1.12 (실측 v0.10) | m_fore=1.2 (예산 상한) | 허용 한계 | 최악 여유 |
|---|---|---|---|---|
| T_J2 | 4.53 N·m | 4.71 N·m | 10 N·m (기어박스 캡 — 모터 출력 12.6) | **2.1×** |
| T_J3 | 4.21 N·m | 4.32 N·m | 9.07 N·m (모터 출력 = 0.56×0.9×20×0.9) | **2.1×** |
