# 토크 예산 (Torque Budget)

PER-002: 최악 조건(팔 수평 완전 신장 + 정격 페이로드 1kg)에서 J2/J3 정적 토크 ≤ 기어박스 정격.
분담 정역학 해석과 토크 계산 전체를 본 문서에 기록·검증한다 (MUST).

## 분담 구조 (MEC-001a)

J3 모터는 어깨부 탑재 + 평행사변형 구동 링크. 중력 모멘트 분담:
- 상완 구간 → J2 액추에이터
- 하완 구간 → J3 액추에이터

## 정적 토크 식

```
T_J2 ≈ g·[(m_p + m_fore)·L1 + m_up·L1/2] − T_rear ≤ T_rated,J2
T_J3 ≈ g·[m_p·L2 + m_fore·L2/2]                  ≤ T_rated,J3
```

- T_rear = 후방 배치 모터 질량(≈0.9kg)에 의한 상쇄 모멘트 (MEC-001c)
- m_p = 페이로드 1.0kg (그리퍼 포함, PER-001)

## 기준값 계산 (L1=0.225m, L2=0.275m)

가정: m_fore(하완+손목) = 0.45kg, m_up(상완) = 0.35kg, T_rear ≈ 0.7N·m

| 관절 | 계산 | 결과 |
|---|---|---|
| T_J2 | 9.81 × (1.45×0.225 + 0.35×0.113) − 0.7 | **≈ 2.9 N·m** |
| T_J3 | 9.81 × (1.0×0.275 + 0.45×0.138) | **≈ 3.3 N·m** |

## 판정

- 기어박스 연속 허용 토크 10 N·m ≥ 3.5 N·m → **리치 500mm 성립** (StepperOnline HG 시리즈 기준, [tbd-research.md](tbd-research.md) TBD-5)
- 모터 출력단 토크 여유: J2 4.1×, J3 2.6× (홀딩 토크 × 전류 90% × 감속비 × 효율 85%)
- 미달 시 **L2 → L1 순으로 축소 (MUST)**, `config/parameters.scad`의 L1/L2 갱신
- 과도 토크(가감속) ≤ 기어박스 순간 허용 토크 15 N·m (MUST)
- 수평 완전 신장 장시간 정지 유지는 기어박스 수명 관점에서 회피 (SHOULD — 안전 요구 아님)
