# 토크 예산 (Torque Budget)

PER-002: 최악 조건(팔 수평 완전 신장 + 정격 페이로드 1kg)에서 J2/J3 정적 토크 ≤ 기어박스 정격.
분담 정역학 해석과 토크 계산 전체를 본 문서에 기록·검증한다 (MUST).

## 분담 구조 (MEC-001a)

J3 모터는 어깨부 탑재 + 평행사변형 구동 링크. 중력 모멘트 분담:
- 상완 구간 → J2 액추에이터
- 하완 구간 → J3 액추에이터

## 정적 토크 식

```
T_J2 ≈ g·[(m_p + m_fore)·L1 + m_up·L1/2] − T_rear ≤ T_rated,J2
T_J3 ≈ g·[m_p·L2 + m_fore·L2/2]                  ≤ T_rated,J3
```

- T_rear = 후방 배치 모터 질량(≈0.9kg)에 의한 상쇄 모멘트 (MEC-001c)
- m_p = 페이로드 1.0kg (그리퍼 포함, PER-001)

## 기준값 계산 v2 (L1=0.225m, L2=0.275m — MG17 데이터시트 확정값, 2026-06-13)

확정값: 모터 질량(카탈로그), 기어박스 질량·효율 90%(데이터시트). 가정 잔여: m_up(상완 구조) = 0.35kg, 후방 모멘트 암 = rear_extension 80mm.

T_rear = (SF2424 0.51 + SF2423 0.38 + MG17-G20 ×2 0.80) kg × 9.81 × 0.08 = **1.33 N·m** (초기 가정 0.7보다 유리)

m_fore는 잠정 가정(0.45kg)과 예산 상한(0.8kg, MEC-007) 양쪽 평가:

| 관절 | m_fore=0.45 (잠정) | m_fore=0.8 (예산 상한) | 허용 한계 | 최악 여유 |
|---|---|---|---|---|
| T_J2 | 2.26 N·m | 3.03 N·m | 10 N·m (기어박스 캡 — 모터 출력 12.6) | **3.3×** |
| T_J3 | 3.30 N·m | 3.78 N·m | 9.07 N·m (모터 출력 = 0.56×0.9×20×0.9) | **2.4×** |
| T_J4 | (손목 롤 — 중력 모멘트 미미) | — | 1.74 N·m 출력 / 기어박스 9 N·m | 충분 |

초기 가정 계산(T_J2 2.9 / T_J3 3.3, HG 시리즈 기준)은 git 히스토리 참조.
