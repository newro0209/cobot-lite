## 1. J2 구동 토폴로지 (v0.7)

J2 동축 직결 + J3만 후방 배치. 상세 비교와 토크 영향은 [torque-budget.md](torque-budget.md)
"J2 토폴로지 결정 기록" 참조. 요지: J2/J3 전부 후방 배치(구 가정)는 J2도 크랭크 링크 구동이
필요해 구조 복잡·가동 범위 제한, MEC-001 표와 충돌. T_rear 0.61 N·m로도 토크 여유 충분.

## 3. 가동 범위 (간섭 검사 확정, `tools/check_asm.ps1`)

(체인∩고정부, 하완∩상완) `intersection()` 부울 — 빈 결과 = 통과. 전 자세 PASS (2026-06-13).

## 3a. 특이점(singularity) 분석 — 운용 엔벨로프 근거

- **접힘각 -90° = 평행사변형 구동 전동각 특이점**: 크랭크가 구동 링크와 일직선이 되어
  토크 전달 불가. 전달률 = sin(전동각), 전동각 = 접힘각 + 90°.
  `env_fold_min = -75°`에서 전동각 15° → 전달률 ≈ 0.26 — 크랭크 측 요구 토크 ≈ 3.9×.
  단, 깊은 접힘 자세는 하완 중력 모멘트 암(∝ cos 성분)도 함께 감소해 절대 요구
  토크가 작음 — 한계각에서 유효 여유 확인. 더 깊은 접힘 필요 시 크랭크 반경 확대 검토
- **접힘각 0° = 완전 신장 특이점**: J2·J3·손목 일직선 — 리치 경계, IK 비결정.
  `env_fold_max = -3°` → 운용 리치 ≈ 499.5mm (공칭 500 대비 -0.5, MEC-006 잠정 목표 내)
- 둘 다 `assembly.scad` robot()이 echo 경고로 알림

## 3b. 링크 꺾임 (팔레타이저식 구조 오프셋, v0.8)

`ua_bend_deg/_pos`, `fa_bend_deg/_pos` (기본 12° / 0.68·0.5). **관절 축 좌표는 직선
L1·forearm_len 기준 그대로** — 꺾임은 빔 형상만 상향 절곡 (니 높이 h = L·pos·(1-pos)·tanθ ≈ 10~12mm).

- 조인트 좌표 계산·링크 기구학 수정 없음 (axes 불변) — 적용 비용 최소
- 빔 하면이 축선 위로 올라가 저자세 작업 시 공작물·지그와의 여유 증가,
  접힘 자세에서 하완↔상완 보 간섭 여유 증가 (그리드 재검증 통과)
- 상완 니는 분할 조인트(95~131) 뒤(x=153)라 소켓/테논 직선 구간 보존
- **무게중심/토크 영향**: 수직 꺾임은 부재 CG의 수평 위치를 바꾸지 않음 → PER-002
  수평 모멘트 식 불변. 질량 증가 +9g(상완)/+3g(하완) 수준 — [torque-budget.md](torque-budget.md) v4 유지.
  J3 액추에이터 후방 배치(T_rear)에 의한 J2 부담 상쇄도 그대로 유지

관련 형상 결정:
- `j2_axis_h` = 90mm: J2 +45°에서 후방 러그 하단이 어깨 플랜지를 1mm 차로 통과 (80mm에서는 충돌)
- `shoulder_tongue_x` = 40mm: 텅 깊이가 J2 상향 한계를 결정 (포크 내 텅 스윕)
- 상완 측판 전방 상단을 z=15로 낮춤: J2 상향 회전 시 평행사변형 정적 핀 타워(z≥38) 회피
- `pl_offset` = 45mm: J2 모터(42각) 코너 스윕 반경 ≈30mm 위로 링크 1 통과

## 4. MEC-004 해석 변형 — 피벗 베어링 위치

MEC-004는 "8mm 숄더 볼트 + 608ZZ ×2의 포크(clevis) 구조"를 요구한다. 구현:

- **J2**: 드라이브 측 피벗 = MG17 출력축(⌀8)이 겸함 — CON-001은 수동 피벗 핀 규칙이므로
  구동축은 비대상(CON-003과 동일 논리). 아이들 측 608ZZ ×2는 **어깨 텅에 안착**, 숄더 볼트가
  상완 플레이트 A(+카운터보어로 머리 플러시 — 구동 링크 평면 간섭 회피)를 관통해 텅 중앙
  M6 너트에 체결.
- **팔꿈치/손목**: 608ZZ ×2를 **텅(내측 부재)에 안착**, 포크(외측 부재)는 볼트 관통.
  베어링 압입부가 항상 텅 측이라 포크 측판을 얇게 유지 — 분담 구조는 MEC-004 의도(모멘트
  지지 이격 배치)와 동일.
- **팔꿈치 볼트 연장**: +Y로 연장해 로커(608ZZ 1개) 피벗을 겸함 — 숄더 길이 ≈56mm 특주급,
  BOM에서 수급 확인 필요. 불가 시 로커 전용 5mm 핀 보스를 텅에 추가하는 대안 있음.
