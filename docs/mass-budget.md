# 질량 예산 (Mass Budget)

MEC-007: 이동부(상완 이후, J3/J4 포함) 질량 합계 **0.8kg 이하 (MUST)**, 그리퍼 제외.
부품별 질량은 OpenSCAD 모델에서 추정하여 본 문서에 기록한다.

PER-002 기준 가정값 (검증 전 잠정):
- 하완 + 손목: 0.45kg
- 상완: 0.35kg

모터 질량은 산요 카탈로그 확정값 ([tbd-research.md](tbd-research.md) TBD-2): SF2422 = 0.30kg, SF2423 = 0.38kg, SF2424 = 0.51kg.
