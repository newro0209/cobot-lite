# 펌웨어 (firmware)

보드 미확정 (TBD-6: Arduino Mega 2560 / ESP32 / 라즈베리파이 피코). 선정 기준: UART + 4채널 STEP/DIR 타이머 출력 성능.

## 책임 범위 (CTL-001 — 이 3가지로 한정, 그 외 구현 금지)

1. UART 명령 수신 — 단순 텍스트 프로토콜 (CTL-002, 예: `J2 -30.0 50` = J2를 -30.0°로 50°/s)
2. 관절별 목표 각도/속도로의 개루프 스테퍼 구동 — 관절별 사다리꼴 프로파일 (CTL-003), 다축 동기 보간 불요
3. 리미트 스위치 기반 호밍 ([docs/homing.md](../docs/homing.md))

좌표 변환·경로 계획·상태 머신 등 모든 판단은 상위 PC 책임.

## 구현 방침

- 자체 구현 기본 (CTL-004) — 오픈소스 CNC 펌웨어 도입은 과설계
- 프로토콜 파서는 교체 가능하게 분리 (CTL-002, 추후 바이너리 전환 대비)
- 보드 확정 후 보드별 설정 디렉터리 구성 (PRJ-001)
